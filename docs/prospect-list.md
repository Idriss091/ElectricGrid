# Prospect list for BESS pilot outreach

## Outreach objective

Find 3 paid pilots for Thesegrid BESS flexible connection pre-screening.

The target pilot is not a SaaS signup. It is a buyer-side pre-feasibility study on a
real, anonymized, consultant-prepared, or client-supplied network case.

## Priority personas

- Head of BESS development
- Grid connection manager
- Technical director
- Project development manager
- Owner's engineer
- Infrastructure investment manager
- Partner or founder for smaller specialist firms

## First message

```text
Bonjour [Prénom],

Je développe Thesegrid, un moteur de pré-faisabilité pour raccordements flexibles BESS.

L'objectif est de classer rapidement des sites candidats, estimer la puissance
ferme/conditionnelle, identifier les contraintes réseau probables, quantifier le
curtailment et recommander une puissance ou une enveloppe flexible avant étude
officielle.

Je cherche 3 pilotes payants avec des développeurs ou bureaux d'études BESS,
idéalement sur un portefeuille de sites ou un cas anonymisé.

Est-ce que le sujet raccordement flexible / gabarit / puissance optimale est actif
chez vous en ce moment ?
```

## Call script

Use the first call to learn, not to over-demo.

Questions:

- How many BESS sites are you screening right now?
- When do you usually discover that a point of connection is not viable?
- Do you test several MW sizes before advancing a site?
- Have you studied flexible connection offers or injection/soutirage gabarits?
- Who performs your first grid studies today?
- What network data could be shared for an anonymized pilot?
- What would make a pre-screening report useful for an investment committee?
- What late-stage rejection or false-positive would this help avoid?

## Pilot offer

Recommended first offer:

- 1 clean client-model site: EUR 5k-8k
- 3-5 candidate sites: EUR 12k-25k
- larger portfolio: EUR 30k+

Do not offer a free pilot unless the prospect provides unusually valuable data,
references, or a public case study.
