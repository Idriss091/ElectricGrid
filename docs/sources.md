# Sources

## Benchmark networks

- SimBench for benchmark networks and annual profiles.

## Power-system simulation

- pandapower for Python-based power flow, optimal power flow, hosting capacity, and time-series analysis.
- OpenDSS for QSTS and more detailed distribution-network validation.

## Hosting capacity and flexible interconnection

- NREL Advanced Hosting Capacity Analysis
  (`https://www.nrel.gov/solar/market-research-analysis/advanced-hosting-capacity-analysis`):
  distinguishes snapshot hosting capacity,
  dynamic hosting capacity, and coordinated flexible interconnection based on
  time-series analysis and probabilistic screens.
- IREC Hosting Capacity Analysis (`https://irecusa.org/our-work/hosting-capacity-analysis/`):
  treats HCA as a grid-transparency and screening tool rather than a replacement for
  detailed interconnection studies.
- DOE i2X DER Interconnection Roadmap
  (`https://www.energy.gov/eere/i2x/doe-distributed-energy-resource-interconnection-roadmap`):
  recommends frequently updated HCA tools and flexible interconnection options to reduce
  upgrade cost and queue friction.
- NREL/IREC Data Validation for Hosting Capacity Analyses
  (`https://www.nrel.gov/news/video/data-validation-for-hosting-capacity-analyses-text`):
  emphasizes model-quality, result-validation, and feedback processes before HCA outputs
  are used commercially.
- NREL temporal decomposition work for QSTS
  (`https://research-hub.nrel.gov/en/publications/temporal-decompostion-of-a-distribution-system-quasi-static-time--2`):
  motivates splitting annual QSTS workloads and reserving full-year studies for targeted
  candidates.

## French public data
